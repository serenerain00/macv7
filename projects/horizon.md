# Horizon Control

## Project Overview

Horizon Control is a surgical navigation concept designed to help surgeons maintain orientation and anatomical point-of-reference while operating within a joint.

The project focused on solving a common challenge during arthroscopic procedures: maintaining spatial awareness while navigating a camera through complex anatomy.

## The Challenge

Traditional screen-based prototypes failed to accurately simulate how surgeons physically interact with surgical equipment.

Testing interaction concepts using a phone or mouse introduced unrealistic ergonomics and reduced confidence in feedback.

I needed a way to replicate actual surgical movement.

---

## Approach

I developed a hardware-assisted prototype.

A 3D-printed surgical camera model was combined with an Arduino sensor board.

The prototype translated physical hand movements into live software interactions.

This allowed surgeons to evaluate concepts using realistic movement patterns rather than abstract screen interactions.

---

## Technical Innovation

I leveraged AI-assisted development workflows to generate and refine C++ code for the Arduino platform.

The hardware communicated with ProtoPie Connect, enabling real-time synchronization between:

- Physical movement
- Tablet interface
- HUD interface

Multiple experiences responded simultaneously to surgeon input.
