# Vision Design System

## Project Overview

The Vision Design System was created to unify multiple Arthrex surgical technology products under a shared design language and implementation framework.

Prior to this initiative, products evolved independently with separate patterns, themes, and design decisions.

The goal was to create a scalable foundation capable of supporting future Vision products while improving collaboration between design and engineering.

---

## My Role

Design System Lead

I owned:

- Design system strategy
- Component architecture
- Design foundations
- Design tokens
- Documentation
- Governance
- Adoption planning

---

## The Challenge

Several products existed with independent experiences:

- CCU
- Trident
- GX

Each product had its own design assets, visual language, and workflows.

Future products required greater consistency while supporting a migration toward a shared dark-theme ecosystem.

---

## Approach

I built the Vision Design System from the ground up.

This included:

- Foundations
- Tokens
- Components
- Patterns
- Behaviors
- Interaction standards

The system was designed to support both current and future products.

---

## Beyond Figma

Traditional design systems often struggle to communicate:

- Motion
- Elevation
- Transitions
- Behaviors
- Interaction patterns

To solve this, I created an interactive documentation platform.

The platform serves both designers and engineers and acts as the source of truth for implementation.

---

## Design-to-Code Workflow

I leveraged Cursor and Claude Code to help migrate Figma variables and system foundations into implementation-ready structures.

The system is built on Vuetify while maintaining a technology-agnostic mindset.
